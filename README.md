# Sonic em Pygame

Versão simplificada inspirada em Sonic, criada em Python e Pygame como
mostrado no vídeo. O jogo tem aceleração, câmera lateral, pulo, anéis e
robôs que podem ser destruídos.

## Como executar

Tenha o Python instalado. Na pasta do repositório, execute:

```bash
python -m pip install -r requirements.txt
python sonic.py
```

No Windows, se o comando `python` não funcionar, use `py` no lugar dele.

Use as **setas esquerda e direita** para correr e pressione **espaço** para
pular. Feche a janela para sair.

## Código passo a passo

O arquivo `sonic.py` contém o jogo completo. A pasta `passos/` mostra as
cinco versões executáveis apresentadas no vídeo: cenário, velocidade, pulo,
anéis e robôs.
